# ⚔️ RPG de Texto em C (Estudo de Estruturas)

Projeto desenvolvido para estudar lógica de programação e a linguagem C.

## 🎯 O que eu aprendi
Neste código, explorei conceitos que ainda não tinha visto na faculdade:
- **Structs:** Para criar os personagens e itens como se fosse um Banco de Dados na memória.
- **Ponteiros:** Para passar o inventário do herói para funções diferentes.
- **Lógica de Jogo:** Loop de batalha, cálculo de dano aleatório e sistema de turnos.

## 🛠️ Como funciona
É um jogo de batalha por turnos rodando no terminal. O jogador controla "Musachi" e pode:
1. Atacar o monstro.
2. Abrir o inventário e trocar de arma (o que altera o dano causado).

## 📝 Nota
Este código foi desenvolvido com auxílio de IA (Gemini) para entender a aplicação prática de Structs e Ponteiros, servindo como base para meus estudos futuros em C.
